Put replacement files here at the same absolute path as the system file, e.g.

  files/system_ex/rnps/apps/NPXS40008/assets/src/modules/<module>/assets/<file>.png

Optional theme music goes next to theme.ini as music.wav (48 kHz, 16-bit, stereo PCM).

The easiest way to build a theme is the Editor at http://<console-ip>:8095, which
finds the right paths, converts your files and verifies them. Real paths are also
listed in /data/ps5-theme/dump/rnps-files-<firmware>.txt on the console.
Only media can be replaced; code and unknown file types are protected.
